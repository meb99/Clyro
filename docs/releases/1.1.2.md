**English** · [Deutsch](#deutsch)

Updates are now easy to spot and install from inside the app.

### Changes
- **Version badge** in the top right, next to the language switch. Click it to check for a new version.
- **New version hint at launch:** Clyro checks for updates every time it starts. When one is available, the badge turns into a highlighted "New version …" button that opens the update dialog. The dialog opens by itself at most once a day per version.
- **Clyro → Check for Updates…** in the app menu.
- Automatic checks can still be turned off under Settings → Updates.

### Installation
If you run Clyro 1.1.1, go to Settings → Updates → **Check Now** and choose **Install and Relaunch**. For a new installation, open the DMG and drag Clyro into Applications. The app is not notarized by Apple, so macOS blocks the first launch. On macOS 15 or later, open Clyro once, then go to System Settings → Privacy & Security and click **Open Anyway**. On macOS 14, right-click the app and choose **Open**. Requires macOS 14 or later on Apple Silicon or Intel.

**Deutsch**

Updates sind jetzt direkt in der App sichtbar und installierbar.

### Änderungen
- **Versionsanzeige** oben rechts neben dem Sprachschalter. Ein Klick sucht nach einer neuen Version.
- **Hinweis beim Start:** Clyro sucht bei jedem Start nach Updates. Gibt es eines, wird die Anzeige zu einer hervorgehobenen Schaltfläche „Neue Version …“, die den Update-Dialog öffnet. Der Dialog erscheint von selbst höchstens einmal am Tag pro Version.
- **Clyro → Nach Updates suchen …** im App-Menü.
- Die automatische Suche lässt sich weiterhin unter Einstellungen → Updates abschalten.

### Installation
Wer Clyro 1.1.1 nutzt, geht auf Einstellungen → Updates → **Jetzt suchen** und wählt **Installieren und neu starten**. Für eine neue Installation die DMG öffnen und Clyro in den Programme-Ordner ziehen. Die App ist nicht von Apple notarisiert, deshalb blockiert macOS den ersten Start. Ab macOS 15 Clyro einmal öffnen, dann unter Systemeinstellungen → Datenschutz & Sicherheit auf **Trotzdem öffnen** klicken. Unter macOS 14 per Rechtsklick → **Öffnen** starten. Voraussetzung: macOS 14 oder neuer, Apple Silicon oder Intel.
