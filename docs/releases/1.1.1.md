A small maintenance release.

### Changes
- **Clean Up and Apps** return to their start screen when you switch to another tab, so results always come from a fresh scan. A scan or cleanup that is still running keeps going.
- Corrected first-launch instructions for macOS 15 and later (see below).
- Project updated to the build settings recommended by Xcode 27; one concurrency warning fixed.

### Installation
Open the DMG and drag Clyro into Applications. If you already run Clyro 1.1.0, it offers the update within a day when automatic checks are on, or right away via Settings → Updates → **Check Now**. The app is not notarized by Apple, so macOS blocks the first launch. On macOS 15 or later, open Clyro once, then go to System Settings → Privacy & Security and click **Open Anyway**. On macOS 14, right-click the app and choose **Open**. Requires macOS 14 or later on Apple Silicon or Intel.

**Deutsch**

Eine kleine Wartungsversion.

### Änderungen
- **Bereinigen und Apps** kehren zum Startbildschirm zurück, sobald ein anderer Tab geöffnet wird. Ergebnisse stammen damit immer aus einem frischen Scan. Ein laufender Scan oder eine laufende Bereinigung läuft weiter.
- Korrigierter Hinweis zum ersten Start unter macOS 15 und neuer (siehe unten).
- Projekt auf die von Xcode 27 empfohlenen Build-Einstellungen umgestellt; eine Nebenläufigkeitswarnung behoben.

### Installation
DMG öffnen und Clyro in den Programme-Ordner ziehen. Wer Clyro 1.1.0 nutzt, bekommt das Update bei aktivierter automatischer Suche innerhalb eines Tages angeboten, oder sofort über Einstellungen → Updates → **Jetzt suchen**. Die App ist nicht von Apple notarisiert, deshalb blockiert macOS den ersten Start. Ab macOS 15 Clyro einmal öffnen, dann unter Systemeinstellungen → Datenschutz & Sicherheit auf **Trotzdem öffnen** klicken. Unter macOS 14 per Rechtsklick → **Öffnen** starten. Voraussetzung: macOS 14 oder neuer, Apple Silicon oder Intel.
